# Ревью и рефакторинг

## Исправлено

- Исходники перенесены из `design/prototype` в `src`. Варианты логотипа остались в архиве дизайна.
- JavaScript разделён на модули: инициализация, анимация контента, портрет, кометы. Сторонние зависимости не добавлены.
- Кнопка паузы теперь прекращает активные появления текста и демонстрацию запроса. Ранее она только блокировала новые появления.
- Кометы реагируют на явное событие изменения режима движения вместо наблюдения за любыми изменениями CSS-классов body.
- CSS развёрнут в читаемый формат с сохранением порядка каскада. Убраны старые варианты геометрии орбит и неиспользуемая анимация их вращения.
- Сборка очищает старый результат после проверки исходников. Основные проверки заменены с assert на явные исключения: они работают и при `python -O`.

## Проверки

- Два регрессионных теста сборки: очистка устаревших файлов и отказ до изменения предыдущего результата при неверном якоре.
- Проверка синтаксиса модулей и успешная сборка восьми публичных файлов.
- Локальный предпросмотр: главный экран, кнопка паузы, отсутствие ошибок JavaScript, ширина 320 px и загрузка изображений.

## Границы проверки

Полный аудит WCAG, измерения производительности на слабых устройствах и матрица браузеров не проводились. В CSS сохранены некоторые поздние переопределения: их перемещение без сравнения всех адаптивных состояний может изменить каскад.

Для запуска теперь требуется локальный HTTP-сервер: JavaScript использует ES-модули. Открывать index.html через file:// не следует. Команда приведена в README.

Версия после рефакторинга опубликована через Cloudflare Direct Upload. Все восемь публичных файлов отвечают HTTP 200 и побайтово совпадают с проверенной сборкой.
