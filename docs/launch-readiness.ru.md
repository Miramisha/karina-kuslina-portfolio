# Публикация и обновление

Основной адрес: https://karina-kuslina.pages.dev/

## Архитектура

Статический сайт на HTML, CSS и JavaScript. Хостинг: Cloudflare Pages, проект `karina-kuslina`, способ публикации Direct Upload. Backend, база данных и платный домен не используются.

## Обновление

1. Изменить файлы в `src/`.
2. Выполнить `python3 scripts/build.py`.
3. Проверить сайт локально.
4. Загрузить содержимое `dist/` в существующий проект Pages. В ZIP файл `index.html` должен находиться в корне.
5. Проверить опубликованную страницу и ресурсы.

Коммит в GitHub сам по себе не обновляет сайт: автоматическая публикация пока не подключена. Папка `dist/` генерируется и не включается в Git.

## Проверено

- Нет горизонтальной прокрутки при ширине 320 и 1440 px.
- Изображения и внутренние ссылки доступны.
- Ссылки на проекты GitHub и Telegram отвечают HTTP 200.
- Сборка проверяет ресурсы, якоря и уникальность идентификаторов.
- Главная страница и ресурсы опубликованного сайта отвечают HTTP 200 без авторизации.

В сборку не входят документы и варианты дизайна. Полный аудит доступности и производительности не проводился.
