# Подготовка к публикации

Макет согласован. Сайт сохраняет архитектуру HTML/CSS/JavaScript без зависимостей, базы данных и отдельного backend.

## Проверено

- Ширина 320 и 1440 пикселей: нет горизонтальной прокрутки.
- Изображения загружаются; внутренние ссылки ведут к существующим разделам.
- Все шесть ссылок GitHub и ссылка Telegram отвечают HTTP 200. Отправка сообщений и писем не выполнялась.
- Сборка проверяет наличие локальных ресурсов и уникальность идентификаторов.
- В сборку входят только главная страница, стили, JavaScript, фото и выбранный логотип. Черновики и документы не публикуются.
- Добавлена SVG-иконка вкладки и текстовые метаданные для ссылок.

## Размещение

Подготовлена статическая сборка для Sites. Первое размещение закрытое; оно предназначено для проверки владельцем. Публичный доступ для работодателей — следующий согласуемый шаг. Платный тариф или домен не приобретались. Статический сайт обслуживается хостингом и не требует включённого личного компьютера.

## Обновление

Изменения вносить в `design/prototype/`, затем запускать `python3 scripts/build.py`. Папка `dist/` генерируется и не включается в Git. После проверки сохранять коммит и новую версию размещения. Одно изменение в GitHub само по себе пока не обновляет размещённый сайт.
